# English PR template

Use for international open-source projects and repositories accepting contributions in English. Follow the repository's own required template first. Scale detail to the change, remove inapplicable optional sections, and replace all instructional text before posting.

Title: A concise description of the concrete resulting behavior, following repository conventions.

```markdown
## Summary

Explain the problem and resulting behavior. Include a concrete before/after example when useful.

## Validation

- List checks actually run and their results. Clearly identify failed or skipped checks.

## Risks and limitations

Include only material limitations or reviewer-relevant risks; omit this section when unnecessary.
```

Add issue links only when verified. Use closing keywords only when the change actually resolves the issue. Include screenshots for visible changes when available and useful; never invent evidence.
