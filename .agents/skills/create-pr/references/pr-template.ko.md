# 한국어 PR 템플릿

한국어로 기여를 받는 한국 프로젝트에 사용한다. 저장소 자체 필수 템플릿을 우선한다. 변경 규모에 맞게 작성하고 불필요한 선택 항목은 제거하며, 게시 전에 안내 문구를 실제 내용으로 교체한다.

제목: 저장소 관례에 따라 변경 결과를 구체적으로 표현한다.

```markdown
## 변경 내용

해결한 문제와 변경 후 동작을 설명한다. 필요하면 구체적인 변경 전후 예시를 포함한다.

## 검증

- 실제 실행한 검사와 결과를 적는다. 실패하거나 생략한 검사를 구분한다.

## 위험 및 제한

검토에 필요한 중요한 제한이나 위험만 적는다. 필요하지 않으면 이 항목을 제거한다.
```

확인한 이슈만 연결한다. 실제 해결한 이슈에만 자동 종료 키워드를 사용한다. 화면 변경은 도움이 되는 실제 스크린샷이 있으면 첨부하고, 검증 근거를 만들어내지 않는다.
